### ✨ Highlights
- 🕯️ **Victorian Nocturne Aesthetic:** Soot-black backgrounds (`#171b1a`) infused with a green cast, wet cobbles, and warm lamplight glow.
- 🎨 **Fine Art Color Palette:** Drawn directly from 19th-century oil paintings by John Atkinson Grimshaw.
- 🖼️ **Public Domain Artwork:** 7 curated nocturne paintings formatted in sharp 16:9 for desktop backgrounds.
- 📓 **Native Obsidian Theming:** Includes a tailored `obsidian.css` theme handled automatically by Omarchy.
- 🚀 **Full Omarchy Integration:** Complete styling for Waybar, terminal applications, and system menus.

---

## 🚀 Installation

Install directly via the Omarchy CLI:

```bash
omarchy theme install https://github.com/imanubdesigner/omarchy-grimshaw-theme
```

Then pick **Grimshaw** from *Style > Theme* in the Omarchy menu.

> **Tip:** If the icons keep the previous theme's colors after switching, close Nautilus (`nautilus -q`) and reapply the theme.

## 🎨 Palette

Everything is generated from a single `colors.toml`.
Soot-black backgrounds with a green cast, pale sage text, and a sage-teal accent. Lamp-yellow and brick-red are preserved for warnings and highlights, the way a single lit window stands out in the paintings.
