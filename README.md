# Grimshaw

A dark, gaslit Victorian nocturne theme for [Omarchy Quattro](https://github.com/basecamp/omarchy).

Soot-black backgrounds, pale sage text, and lamp-yellow accents. Moss, olive,
harbour teal, and a touch of brick red carry the palette. Every colour is
taken from the wet cobbles, green night skies, and shop windows of John
Atkinson Grimshaw's moonlit docks and streets.

![Preview](preview.png)

## Installation

```
omarchy theme install https://github.com/imanubdesigner/omarchy-gaslight-theme
```

## Backgrounds

Seven Grimshaw nocturnes in 16:9:

- Canny Glasgow
- November Moonlight
- Quai de Paris, Rouen
- Reflections on the Thames, Westminster
- Shipping on the Clyde
- Silver Moonlight
- Whitby at Night
